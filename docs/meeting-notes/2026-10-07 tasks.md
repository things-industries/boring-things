- Tasks types (deadline, recurrent, one off) vs task features
- Features
    - due date
    - recurrence (number of days for next task)
    - importance (how bad is it if you don't do it)
        - Critical (renew visa for country you live in)
        - important (renewing insurance)
        - recommended (cleaning filter on an air conditioner, salt in dishwasher),
        - nice to have (cleaning windows, oiling locks)
    - visibility horizon (number of days) - task shows up in timeline when due date is within that period.
    - completion behaviour - deterministic vs chat about it
        - deterministic: could be set to update/increment a specific field or to prompt the user in some way (design a form that prompts for updated info)
        - chat about it: AI decides on update actions

- Adding tasks from suggested

- Events
    - attached to thing, optional issue
    - primarily created by AI
    - no recurrence
