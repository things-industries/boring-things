# Archived documentation

Documents here are historical records. Freeze their content after archiving. Record changes and corrections in the current documentation.

Add YAML front matter when archiving a document. Set `archived` to the archive date in `YYYY-MM-DD` format. Add an optional `reason` and link to the current document below the title when there is a successor. Use Git history for superseded material that needs no place in the documentation map.
