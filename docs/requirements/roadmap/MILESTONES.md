# Milestones

## POC - sprint 1

The app can be used locally to register, log in, add and manage Things.

- Scaffold a project
- Create data and blob storage abstractions and connect them to something simple for local testing (plan to connect to Postgres and Vercel blob storage in production)
- Create an initial data structure.
- Populate an initial set of placeholder Categories
- Create UI for auth, things dashboard, thing view, thing editor, add thing.  Empty placeholder pages for Timeline, Insights and Assistant
- Implement integration with OpenAI and use it for smart autosuggest during thing creation, and to Extract data from submitted text/photos/documents
- Implement a design system such that pages/screens can reuse components
- Implement simple username/password for auth, with no email validation or password recovery (briding solution to be replaced in M2)
